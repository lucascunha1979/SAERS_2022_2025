# Publicação do painel SAERS no GitHub Pages

Este diretório está preparado para ser publicado diretamente no GitHub Pages.

## Conteúdo

- `index.html`
- `styles.css`
- `app.js`
- `.nojekyll`
- `dados/`
- `mapas/`
- `docs/`

## GitHub Pages

Após enviar todos os arquivos para a branch `main`:

1. abra **Settings**
2. abra **Pages**
3. em **Build and deployment**, escolha **Deploy from a branch**
4. selecione:
   - Branch: `main`
   - Folder: `/ (root)`
5. clique em **Save**
